## Slice 0 — Asset provenance
Obtain the generated PNG from the project conversation attachment; confirm exact image, file rights, palette and readability. Keep it as a **reference sheet**, not the production sprite atlas. Create original transparent sprite frames with consistent grid, pivot, outline and pixel scale. Do not claim the binary is present until committed and checked.

## Slice 1 — History content
Create a curated, versioned set of 4–6 history flags. Source each historical statement directly. Include a counterpoint that challenges the main essay. Keep unpublished drafts visibly distinct. Validate every public source link.

## Slice 2 — Character specimen
Build a standalone, testable Motte specimen with idle, move, land, flag and sleep states; include pause/dismiss. Establish a bounded safe-area movement policy. Verify it never overlays controls or interrupts text selection.

## Slice 3 — Editorial integration
Attach history anchors to the opening, Index, Switchboard and convergence. Reveal the same semantic note in static mode. Keep the creature optional and unobtrusive. Avoid forced scroll choreography.

## Slice 4 — Verification
Check browser at 390/768/1440, reduced motion, keyboard, focus, screen reader structure, asset paths, page performance and dismissal. Add regression tests for history-source status and character boundaries. Validate GitHub Pages `/postack-underflow/` subpath.

## Acceptance
A reader can access every historical observation without seeing animation. The moth never obstructs content. A planted flag is meaningful and source-linked. The creature feels like a strange desktop pet, not a chatbot. Visual quality is reviewed against the actual reference PNG. Nothing is deployed or merged until approved.
