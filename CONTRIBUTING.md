# Contributing

This is a public, early-stage research prototype. Critique, prior art, test queries, small reproducible examples, and protocol expertise are welcome.

Please distinguish: **observation / hypothesis / implementation / measured result**. Include original source links and versions. Do not submit secrets, private chats, proprietary code, or unattributed AI-generated claims. Do not post on behalf of other people. Keep dissent visible and civil.

Good first contributions: suggest relevant ATProto Lexicons, propose labeled retrieval queries, identify existing problem-oriented indexes, test how portable comments work, or point out flaws in the thesis.

Changes should be narrowly scoped, documented, and reviewable. No automated publishing or external account actions without explicit permission.
